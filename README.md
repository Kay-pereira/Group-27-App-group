# 📝 TooPDF App (Offline PDF Generator)

A lightweight, browser-based PDF generator that allows users to enter text, upload or drag-and-drop an image, preview it, and generate a downloadable PDF — all offline.

## Features

- ✅ Text to PDF conversion
- 🖼 Image upload with drag & drop support
- 👀 Live image preview before download
- 📦 Fully offline (no internet needed)

## 📂 Project Structure
toPDF-app/
├── index.html # Main HTML interface
├── style.css # Custom styles
├── app.js # PDF logic & image handling
├── jspdf.umd.min.js # jsPDF library (offline version)
└── background.jpg # Optional background image


##  Built With

- HTML
- CSS
- JavaScript
- [jsPDF](https://github.com/parallax/jsPDF)

##  How It Works

1. Enter text in the input area
2. Upload or drag & drop an image
3. Preview the image
4. Click **Download as PDF**
5. The browser downloads a PDF containing your text and image

##  Preview

the app displays a preview of your text and/or the image file uploeaded (.jpg)

## 📥 How to Use

1. Clone or download the project
2. Open `index.html` in your browser (no internet needed!)
3. Type your content and upload an image
4. Click the download button to save your PDF
